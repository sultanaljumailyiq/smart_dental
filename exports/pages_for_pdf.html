مخططات صفحات تطبيق "العيادة الذكية" للطباعة (PDF)

مستند جاهز للطباعة: كل صفحة تحوي الترتيب من أعلى إلى أسفل مع عناصر واجهة المستخدم والنصوص التي توضع حرفياً.

الصفحة 1 — الصفحة الرئيسية (Landing / زائر / مريض)

رأس الصفحة

  1. شعار: "العيادة الذكية"
  2. حقل بحث placeholder: "ابحث..."
  3. روابط: "الخدمات الطبية"، "المتجر"، "المجتمع"، "التوظيف"، "التعليم"
  4. أيقونات: إشعارات، رسائل، سلة، الملف الشخصي
  5. أزرار دور: "هل أنت طبيب؟"، "هل أنت مورد؟"، و"تسجيل / دخول"

المنطقة الرئيسية (بانر)

  1. عنوان جذاب: "ابحث عن أفضل رعاية لابتسامتك"
  2. وصف موجز: ��ص يبدأ بشرح سريع للفائدة
  3. زر CTA: "ابدأ الآن"

محتوى الصفحة

  1. اختصارات سريعة: بطاقات لخدمات شائعة (التشخيص، استشارة عن بُعد، تنظيف...)
  2. قسم "الخدمات الطبية": شبكة بطاقات لكل خدمة (صورة، اسم، وصف موجز، مدة، أزرار: "تفاصيل" و"احجز الآن")
  3. قسم "العيادات القريبة": خريطة مصغّرة + قائمة بطاقات العيادات (اسم، تقييم، مسافة، زران: "عرض" و"احجز")
  4. قسم "المقالات والدورات": بطاقات محتوى مع زر "اقرأ المزيد"
  5. شريط CTA ثانوي لعرض عاجل أو تذكير

الفوتر

  • روابط: "عن المنصة"، "اتصل بنا"، "الأسئلة الشائعة"، "سياسة الخصوصية"
  • تواصل اجتماعي وحقوق النشر: "© {YEAR} العيادة الذكية - جميع الحقوق محفوظة"
ملاحظة: زر "هل أنت طبيب؟" و"هل أنت مورد؟" يقودان لصفحات خاصة بالتسجيل مع زر "تسجيل سريع".

الصفحة 2 — صفحة نتائج البحث / قائمة العيادات

الترتيب

  1. رأس الصفحة كما في العامة
  2. شريط فلترة أفقي: بحث نصي + قوائم منسدلة (المحافظة، التخصص، التأمين)
  3. معاينة خريطة مصغّرة على اليسار أو أعلى
  4. قائمة النتائج على اليمين أو أسفل الخريطة: بطاقات كل عيادة مع أزرار "عرض" و"احجز"
  5. تذييل بسيط وروابط مساعدة

الصفحة 3 — صفحة تفاصيل العيادة / الخدمة

  1. رأس الصفحة
  2. رأس المحتوى: اسم العيادة/الخدمة + تقييم + مسافة + زر "احجز الآن" بارز
  3. معرض صور/فيديو صغير
  4. تبويبات للمعلومات: عن العيادة، الفريق، الخدمات، ساعات العمل
  5. قسم التقييمات والآراء
  6. زر الحجز يظل ظاهراً أثناء التمرير

الصفحة 4 — شاشة الحجز المبسّط (بدون تسجيل)

  1. عنوان: "أدخل بيانات الحجز"
  2. ملخص الخدمة/العيادة والموعد
  3. حقول: "الاسم"، "رقم الهاتف"، "البريد الإلكتروني (اختياري)"
  4. زر: "أرسل رمز التحقق" → إدخال الـOTP → زر "تأكيد"
  5. صفحة تأكيد: عرض رقم الحجز وتفاصيله + أزرار "طباعة" و"إلغاء"

الصفحة 5 — صفحة عامة للطبيب (قبل التسجيل)

  1. رأس الصفحة
  2. عنوان: "مساحة الأطباء"
  3. وصف موجز للفوائد
  4. زر: "تسجيل سريع للأطباء"
  5. قائمة مزايا بالبطاقات: إدارة العيادة، التقويم، المجتمع، المتجر

الصفحة 6 — صفحة عامة للمورد (قبل التسجيل)

  1. رأس الصفحة
  2. عنوان: "مساحة الموردين"
  3. وصف وفوائد سريعة
  4. زر: "تسجيل سريع للموردين"
  5. مقتطف من لوحة المورد: مثال "أضف منتجك الآن"

الصفحة 7 — مركز الأطباء (بعد تسجيل)

  1. رأس عام + شريط فرعي داخلي للمركز: روابط أقسام (لوحة التحكم، إدارة العيادات، الحجوزات، العيادة الذكية، المتجر، التوظيف، المجتمع، الإشعارات، المهم والتذكيرات، الرسائل، الملف الشخصي، الإعدادات)
  2. موجز علوي: بطاقات سريعة (حجوزات اليوم، إشعارات)
  3. محتوى افتراضي: قائمة الحجوزات أو التقويم
  4. منطقة إشعارات ومهام

الصفحة 8 — إدارة العيادة (داخل مركز الأطباء)

  1. رأس داخلي: اسم العيادة + حالة التفعيل
  2. تبويبات: معلومات عامة، السجلات والمرضى، الطاقم وساعات العمل، الموارد
  3. قوائم المواعيد مع أزرار تعديل وحفظ
  4. أزرار سريعة: "اضبط ساعات العمل"، "أضف موظف"

الصفحة 9 — العيادة الذكية (داخل مركز الأطباء)

  1. عنوان: "العيادة الذكية"
  2. قائمة سريعة بالمرضى القادمين مع ملاحظات
  3. أدوات مساعدة: إضافة ملاحظة، تحميل صورة، اقتراح علاج
  4. زر: "فتح ملف المريض"

الصفحة 10 — مركز الموردين (بعد تسجيل)

  1. رأس عام + شريط فرعي للمورد: روابط (المنتجات، الطلبات، العروض، التقارير، الإعدادات)
  2. موجز: بطاقات "طلبات جديدة"، "مخزون منخفض"، "مبيعات اليوم"
  3. شبكة المنتجات مع أزرار تعديل وإيقاف
  4. لوحة الطلبات مع أزرار تغيير الحالة وإدخال رقم تتبع

الصفحة 11 — إدارة المنتجات (داخل مركز الموردين)

  1. عنوان: "المنتجات"
  2. زر: "أضف منتج"
  3. شبكية عرض المنتجات: صورة، اسم، سعر، مخزون، زر "تعديل"
  4. نموذج إضافة/تعديل: اسم، صور، سعر، كمية، وصف، زر "حفظ"

الصفحة 12 — إدارة الطلبات (داخل مركز الموردين)

  1. عنوان: "الطلبات"
  2. قائمة الطلبات: حالة، اسم المشتري، تفاصيل، زر "تفاصيل" و"تغيير الحالة"
  3. تفاصيل الطلب: شحن، رقم تتبع، طباعة فاتورة

الصفحة 13 — لوحة إدارة النظام (Admin)

  1. رأس: "لوحة إدارة النظام"
  2. موجز علوي: أرقام سريعة (مستخدمون، عيادات، موردون، معاملات)
  3. روابط: المستخدمون، العيادات والموردون، المحتوى، المالية، سجلات التدقيق
  4. أزرار إدارة: اعتماد/حظر/تعديل/التبديل إلى دور

الصفحة 14 — صندوق الرسائل والمراسلات

  1. عمود المحادثات: قائمة المحادثات مع لمحة آخر رسالة ووقت
  2. نافذة المحادثة: الرسائل المتسلسلة + حقل كتابة "اكتب رسالة..." + زر "إرسال"

الصفحة 15 — مركز الإشعارات

  1. قائمة إشعارات مرتبة زمنيًا
  2. أمثلة: "حجز جديد"، "طلب جديد"، "تنبيه مخزون"
  3. كل إشعار: نص موجز، وقت، زر "عرض" أو إجراء سريع
